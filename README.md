# GrowthPilot – AI Marketing & Business Growth Platform

GrowthPilot analyzes a company's entire digital presence and generates a **Business Growth Score** with AI-powered actionable insights.

```
                         GROWTHPILOT
                              │
             ┌────────────────┼────────────────┐
             ↓                ↓                ↓
          WEBSITE           GOOGLE           SOCIAL
             │                │                │
          SEO            Search Console     Instagram
          Content        Analytics          Facebook
          Conversion     Business Profile   TikTok
                                             YouTube
                                             LinkedIn
                              │
                              ↓
                       ┌──────────────┐
                       │  AI ENGINE   │
                       └──────┬───────┘
                              ↓
                    BUSINESS GROWTH SCORE
                              ↓
                    ACTIONABLE INSIGHTS
                              ↓
                    "DO IT FOR ME" AI
```

## Platform Modules

| Module | Description |
|---|---|
| **Dashboard** | Overview of Business Growth Score and top priority actions |
| **Website** | SEO analysis, content quality scoring, and conversion optimization |
| **Google** | Search Console, Analytics, and Google Business Profile |
| **Social Media** | Instagram, Facebook, TikTok, YouTube, and LinkedIn performance |
| **AI Engine** | Explains how the Business Growth Score is computed |
| **Actionable Insights** | AI-generated prioritized list of growth opportunities |
| **Do It For Me AI** | AI automatically implements improvements on your behalf |

## Getting Started

```bash
cd growthpilot
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the platform.

## Tech Stack

- **Next.js 16** (App Router) with TypeScript
- **Tailwind CSS** for styling
- **Static mock data** demonstrating the full platform UX
